## 🌟 Overview

PRODIGY is a modern, high-end creative agency website crafted to deliver a luxurious digital experience. Built with a strong focus on aesthetics, performance, and user engagement, the website combines advanced animations, premium visual effects, and responsive layouts to create a memorable brand presence.

The project showcases branding expertise, graphic design services, motion graphics, UI/UX design, digital campaigns, and portfolio presentations through an elegant and interactive interface.
